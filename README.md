# Starfield Galaxy Generator

A highly detailed galaxy generator supporting multiple galaxy types, star system management, and hyperspace lane creation for sci-fi worldbuilding.

## Features

- **Multiple Galaxy Types**:
  - Spiral Galaxies (based on density wave theory)
  - Ring Galaxies
  - Cluster Galaxies
  - Galaxy Merging and Hybrid Types

- **Star System Management**:
  - Interactive star system selection
  - Custom labeling and naming
  - System properties and metadata

- **Hyperspace Lanes**:
  - Automatic lane generation
  - Custom route planning
  - Travel time calculations

- **World Building Tools**:
  - Auto-population of systems
  - Export capabilities for sci-fi wikis
  - Detailed galaxy visualization

## Installation

```bash
npm install
```

## Development

```bash
npm run dev    # Development build with watch
npm run serve  # Development server
npm run build  # Production build
```

## Usage

Open `dist/index.html` in a web browser or use the development server to access the galaxy generator interface.
